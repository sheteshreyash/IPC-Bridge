# Sprint 3 - GPIO Interrupt (IRQ) Validation

## Purpose

Verify that the NVIDIA Jetson Nano correctly detects the `DATA_READY` interrupt generated by the STM32H743ZI.

The interrupt indicates that a telemetry packet is ready for SPI transfer.

## Objective

Validate:

- GPIO interrupt registration
- rising-edge detection
- interrupt frequency
- stable interrupt handling

This validation establishes the IRQ infrastructure reused by Sprint 4.

## Platform

### Producer

- STM32 NUCLEO-H743ZI

### Consumer

- NVIDIA Jetson Nano P3450 4GB
- L4T R32.7.1
- Linux 4.9.337-tegra
- AArch64

### Interrupt

- DATA_READY
- Jetson GPIO200
- rising edge

## Prerequisites

- custom Sprint 3 Device Tree active
- `telem0_driver.ko` compiled and loaded
- `/dev/telem0` created
- STM32 firmware running

## Validation Procedure

Verify driver:

```bash
lsmod | grep telem0
```
