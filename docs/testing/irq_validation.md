# Sprint 3 - GPIO Interrupt (IRQ) Validation

## Purpose

Verify that the NVIDIA Jetson Nano correctly detects the DATA_READY interrupt generated by the STM32H743ZI.

The interrupt confirms that a new telemetry packet is ready for SPI transfer.

---

## Objective

Validate

- GPIO interrupt registration
- Rising-edge detection
- Interrupt frequency
- Stable interrupt handling

before enabling SPI packet transfers.

---

## Hardware

Producer

- STM32H743ZI

Consumer

- NVIDIA Jetson Nano

Interrupt

- DATA_READY GPIO

---

## Prerequisites

- JetPack installed
- SPI enabled
- GPIO configured
- telem0_driver compiled
- telem0_driver inserted
- STM32 firmware running

---

## Validation Procedure

Verify driver insertion

```bash
lsmod | grep telem0
```

---

## Check kernel log

```bash
sudo dmesg
```

---

## Monitor interrupts

```bash
watch -n1 "cat /proc/interrupts | grep telem0"
```

or

```bash
watch -n1 cat /proc/interrupts
```

depending on the final IRQ registration.

---

## Expected Result

Interrupt count continuously increases while STM32 produces telemetry.
Example

- IRQ 208
- 125
- 250
- 375
- 500

---

## Pass Criteria

- Driver loads successfully
- IRQ registered
- Interrupt count increases
- No kernel warnings
- No missed interrupts

---

## Failure Cases

- IRQ never increments
- Wrong GPIO
- Wrong polarity
- Floating signal
- Wiring error
- Driver probe failure

---

## Notes

- This test validates only GPIO interrupt delivery.
- SPI transfer is verified separately.
