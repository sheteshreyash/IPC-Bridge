# Windows 11 Setup

## Purpose

Windows is secondary in this project.
It can be used for:

- STM32CubeIDE
- STM32CubeProgrammer
- serial terminal tools
- Git for Windows
- viewing docs

## Install

- Git for Windows
- STM32CubeIDE
- STM32CubeProgrammer
- PuTTY or H-Term
- VS Code if needed

## Notes

- Keep STM32 work primarily on Ubuntu
- Use the same GitHub account on both Windows and Ubuntu
- Prefer Ubuntu for build reproducibility
